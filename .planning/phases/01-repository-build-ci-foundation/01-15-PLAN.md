## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
Close the verification gap CR-01 (blocker for Success Criterion 5 / AIDEV-06) and review finding WR-03: the
`governance-approved` gate decides only on a complete pull request file list, and fails closed whenever it cannot
have one.

Gap reason (01-VERIFICATION.md): the `List changed files` step pipes `gh api --paginate` into a jq slurp with an
empty-array fallback under GitHub's default `bash -e` (no pipefail). Empty `gh` output becomes `[]`, `check-pr.sh`
prints "no governed file is touched", and `governance-success` goes green without evaluating anything. The existing
39-case `test-check-pr.sh` never exercises that step. Separately, the files API silently truncates at 3000 files, and
governed paths sort late, so a large pull request can push them out of the list (WR-03).

Purpose: Success Criterion 5 ("a pull request fails CI if it touches governance files without the label") holds
under transient API failures and API truncation, and the listing becomes code that is tested like the gate itself.
Output: `scripts/governance/list-pr-files.sh` with fake-gh tests, the rewired `governance.yml` step, the limit rule in
`check-pr.sh`, and the disposition record for CR-01 and WR-03.

Scope: CR-01 and WR-03 only. WR-01 and WR-04 are plans 01-17 and 01-16. WR-02 is deferred by the author (recorded
in 01-REVIEW-DISPOSITION.md) and IN-01..IN-05 are out of scope; this plan touches none of them.

Governed paths: this plan necessarily edits `.github/workflows/governance.yml` and `scripts/governance/**`. Claude
Code's ask rules prompt the author before each such edit; that is expected, not a blocker. The phase pull request
carries the `governance-approved` label anyway. No GitHub-side write happens in this plan.

Execution environment (applies to every command here): run Gradle as `mise x -- ./gradlew ...` (bare `./gradlew`
fails `verifyTaplo`/`verifyShfmt` by design) and tools as `mise x -- <tool>`. Keep every `<automated>` command a
single plain command: the session harness refuses compound commands that contain git or gh tokens, including
`.github` paths. Never run `git stash`. Never run `lefthook install` (only `lefthook run --no-auto-install`).
`.planning/config.json` must not change. `editorconfig-checker` is not part of `./gradlew check`, so run it
separately. macOS ships bash 3.2: no associative arrays, and no expansion of a possibly empty array under `set -u`.
</objective>
