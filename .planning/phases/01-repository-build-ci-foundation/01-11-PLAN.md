## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
Renovate proposes grouped, labelled updates with a 7-day minimum release age for every version source, and
automerges only the narrow set D-12 allows.

Purpose: CICD-04, and the "Renovate covers all of these sources" clause of INFRA-09 and TOOL-02.
Output: `renovate.json5`.

The Mend app is installed by the author in plan 01-14 (D-11 approval gate). GitHub Actions extraction is
re-verified in plan 01-12 once `ci.yml`, `governance.yml` and `labels.yml` all exist. This plan runs after plan
01-10, so the labels Renovate applies are checked against `.github/labels.yml` when they are written.

Execution environment (from plans 01-04 and 01-05 on): Spotless needs Node, shfmt and taplo from `mise.toml`/`.nvmrc`, so run
every Gradle command that formats or checks (`spotlessApply`, `spotlessCheck`, `check`, `build`, the formatting
TestKit tests) as `mise x -- ./gradlew …` unless mise is activated in the shell; this plan's commands assume it.
</objective>
