## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
The single `./gradlew spotlessApply` also formats TOML (taplo), shell scripts (shfmt plus the SPDX header) and the
remaining text artifacts (properties, profiler scenarios, text and dotfile configs), so every artifact type in the
repository has an auto-format step that agrees with `.editorconfig`.

Purpose: completes TEST-09's formatting surface (D-05) and the project constraint that every produced artifact is
auto-formatted and style-checked; puts the SPDX header on shell scripts (INFRA-16) before the first script lands
(plans 01-08 and 01-09); proves `.editorconfig` agrees with shfmt and taplo (INFRA-14).
Output: `toml`, `shell` and `misc` formats in `courses.root`, `.taplo.toml`, `config/spotless/license-header-shell.txt`,
extended `FormattingFunctionalTest`.

Split note: this plan is the second half of the formatting work that plan 01-04 starts (Prettier, `verifyNodeVersion`,
`.editorconfig`), split out to keep each plan inside the context budget; the order of the work is unchanged.

Formatting side effects: the repository-wide `spotlessApply` reformats `mise.toml` and `gradle/libs.versions.toml`
with taplo (listed in `files_modified` as reformat-only). If any other file changes, commit it with the task and
list it in the SUMMARY.

Execution environment (from plan 01-04 on): Spotless needs Node, shfmt and taplo from `mise.toml`/`.nvmrc`, so run
every Gradle command that formats or checks (`spotlessApply`, `spotlessCheck`, `check`, `build`, the formatting
TestKit tests) as `mise x -- ./gradlew …` unless mise is activated in the shell; this plan's commands assume it.
</objective>
