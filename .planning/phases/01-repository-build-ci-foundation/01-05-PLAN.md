## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
The repository is REUSE-compliant with a minimal README that shows the REUSE badge and the quick start, and
`.gitattributes` makes line endings, binaries and generated or documentation files explicit, with the committed
tree normalised.

Purpose: INFRA-16 and the README D-23 asks for; INFRA-13 normalisation that the hook (plan 01-07) and CI
(plan 01-11) enforce.
Output: `REUSE.toml`, `LICENSES/`, `README.md`, `.gitattributes`, a normalised index.

Phase 1 slice: the README is minimal here and completed in Phase 13 (GH-02, DOC-01). The REUSE API badge turns
green after the author registers the repository at api.reuse.software (author-only step in plan 01-13).
The repository-wide `spotlessApply` in this plan only formats this plan's new files (the tree is already
formatted by plan 01-04); if it changes a file another plan owns, stop and report instead of committing it.

Execution environment (from plan 01-04 on): Spotless needs Node, shfmt and taplo from `mise.toml`/`.nvmrc`, so run
every Gradle command that formats or checks (`spotlessApply`, `spotlessCheck`, `check`, `build`, the formatting
TestKit tests) as `mise x -- ./gradlew …` unless mise is activated in the shell; this plan's commands assume it.
</objective>
