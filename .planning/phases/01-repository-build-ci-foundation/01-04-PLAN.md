## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
The single `./gradlew spotlessApply` formats JSON, JSON5, YAML and Markdown with Prettier as well as Kotlin, with
Node verified against `.nvmrc`, and `.editorconfig` agrees with every formatter, so CI and the hook can enforce
formatting everywhere.

Purpose: extends TEST-09's formatting surface beyond Kotlin (D-05) toward the project constraint that every
produced artifact is auto-formatted and style-checked; gives the hook and CI their editorconfig check (INFRA-14).
Output: Prettier format in `courses.root`, `VerifyNodeVersion` task, `.prettierrc.yaml`, `.editorconfig`,
`.editorconfig-checker.json`, `FormattingFunctionalTest`.

Split note: TOML (taplo), shell (shfmt plus the SPDX header) and the generic text formats are plan 01-05, which
extends `courses.root` and `FormattingFunctionalTest` right after this plan; the split keeps each plan inside the
context budget without changing the order of the work.

Formatting side effects: the repository-wide `spotlessApply` reformats files earlier plans created
(`docs/tooling.md`, `config/detekt/detekt.yml`; listed in `files_modified` as reformat-only). Earlier plans wrote
their other files whitespace-clean; if any other file changes, commit it with the task and list it in the SUMMARY.

Phase 1 slice: TEST-09's TS/TSX formatting arrives with Biome in Phase 5. Line endings (`.gitattributes`) and
REUSE compliance are plan 01-06.

Execution environment (from plan 01-04 on): Spotless needs Node from `.nvmrc` (and, from plan 01-05 on, shfmt and
taplo from `mise.toml`), so run every Gradle command that formats or checks (`spotlessApply`, `spotlessCheck`,
`check`, `build`, the formatting TestKit tests) as `mise x -- ./gradlew …` unless mise is activated in the shell;
this plan's commands assume it.
</objective>
