## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
Expansion of the build tracer: `./gradlew check` formats-checks, analyses and documents every Kotlin source —
the sample module and `build-logic` itself — through conventions (ktfmt + SPDX headers, strict detekt with the
`comments` rules, Dokka `failOnWarning`), the daemon JVM criteria come from `.java-version`, and a TestKit
`functionalTest` suite proves the conventions in isolation under configuration cache and isolated projects.

Purpose: the quality bar of every later module is set here, as conventions rather than per-module configuration
(D-04, D-06, D-07, D-19); the reusable `GradleFixture` is what every governance and formatting check reuses.
Output: `courses.root`, extended `courses.kotlin-library`, root `build.gradle.kts`, detekt and Spotless config,
generated `gradle/gradle-daemon-jvm.properties`, `functionalTest` suite with `GradleFixture` and two test classes.

Phase 1 slice: TEST-13 here covers Kotlin (detekt); Biome for TypeScript arrives with the frontend in Phase 5.
Non-Kotlin formatting is plans 01-04 (Prettier, `.editorconfig`) and 01-05 (TOML, shell, other text files).
