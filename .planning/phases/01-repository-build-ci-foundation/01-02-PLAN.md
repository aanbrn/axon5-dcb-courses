## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
A contributor runs `mise install` and gets every non-Gradle CLI tool at a pinned, checksum-verified version,
with the JDK and Node.js versions taken from their single source files, and a tool inventory that points to
each version source.

Purpose: the hook (plan 01-05), CI (plan 01-09), Renovate (plan 01-08) and the REUSE/editorconfig checks
(plan 01-03) all depend on these tools. The package-legitimacy gate must be answered before the first install.
Output: `mise.toml`, `mise.lock`, `.nvmrc`, `docs/tooling.md`.

Note on task order: Task 1 is the mandatory package-legitimacy gate (protocol: it must precede any install),
so the tracer is Task 2. The Gradle cross-check of the inventory against `mise.toml` is plan 01-04 (D-17);
this plan proves the same property with a shell one-liner.

Phase 1 slice of TOOL-01: the inventory covers every tool Phase 1 uses plus host prerequisites; the tools
TOOL-01 names that later phases introduce (pnpm, pack, trivy, grype, syft, cosign, Structurizr, act, docker
compose usage) are listed in a "Planned tools" table without a version source, and each later phase moves its
rows into the main table when it pins the tool.
</objective>
