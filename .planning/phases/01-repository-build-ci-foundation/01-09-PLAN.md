## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
Labels are managed as code and synced by CI, every pull request — GSD-generated, Renovate or manual —
starts from one template that mirrors the `/gsd-ship` body, and two build checks keep repository metadata from
drifting: the PR template against `.planning/config.json`, and the tool inventory against `mise.toml`.

Purpose: GH-11 (with the D-18 groups the Renovate rules in plan 01-10 and the governance gate in plan 01-08
rely on), GH-08, and the D-17 cross-check that makes TOOL-01's inventory and TOOL-02's pins agree.
Output: `.github/labels.yml`, `.github/workflows/labels.yml`, `.github/PULL_REQUEST_TEMPLATE.md`, `PrTemplateCheck`,
`ToolingTableCheck`, two TestKit test classes. The repository-wide `spotlessApply` runs here only format this
plan's new files; if one changes a file another plan owns, stop and report instead of committing it.

Bootstrap note (Pitfall 11): the sync job runs only after this workflow reaches `main`, so `governance-approved`
is created manually before the phase PR (plan 01-13). The first sync deletes labels not in `labels.yml`,
including GitHub's default labels — this is listed in the plan 01-13 approval summary.

Execution environment (from plan 01-04 on): Spotless needs Node, shfmt and taplo from `mise.toml`/`.nvmrc`, so run
every Gradle command that formats or checks (`spotlessApply`, `spotlessCheck`, `check`, `build`, the formatting
TestKit tests) as `mise x -- ./gradlew …` unless mise is activated in the shell; this plan's commands assume it.
</objective>
