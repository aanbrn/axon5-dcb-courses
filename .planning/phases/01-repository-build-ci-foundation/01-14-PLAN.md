## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
The declared GitHub-side configuration — ruleset, merge settings, security features, the `governance-approved`
label and the optional configuration-cache encryption key — reaches the live repository only after the author
approves the exact delta list and runs the apply commands personally (D-15); the executor then verifies the
result read-only and records which author-only steps (Renovate app, drift-check token, REUSE registration) are
done or deferred.

Purpose: the ROADMAP approval gate for GH-06/GH-07 and the D-11/D-15 approval items; closes the walking
skeleton's "PR → `main` under the ruleset" leg, which `/gsd-ship` then exercises on the phase PR.
Output: live repository settings matching the declared files; no repository files change.

No tracer task: this plan performs only approval-gated outward actions. The end-to-end path (apply script ↔
GitHub API) was proven read-only by plan 01-13's tracer (`--dry-run` against the live repository).
</objective>
