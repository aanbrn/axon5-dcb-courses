## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
Every commit is formatted and screened before it leaves the contributor's machine, fast enough to keep
(D-08), and the build's performance has committed gradle-profiler scenarios and a recorded baseline (D-20).

Purpose: TEST-09's "pre-commit hook formatting changed files", the local half of CICD-08 and CICD-06, and
INFRA-10's profiler and Build Scan clauses.
Output: `lefthook.yml`, `scripts/format-staged.sh`, `performance.scenarios`, `docs/performance.md`.

Execution note: verify the hook with `lefthook run pre-commit`; do not run `lefthook install` during phase
execution, because `.git/hooks` is shared by every worktree and parallel plans in this wave would start
running a hook whose config is not yet in their tree. Contributors install it once per clone as the README
quick start says.

Execution environment (from plan 01-04 on): Spotless needs Node, shfmt and taplo from `mise.toml`/`.nvmrc`, so run
every Gradle command that formats or checks (`spotlessApply`, `spotlessCheck`, `check`, `build`, the formatting
TestKit tests) as `mise x -- ./gradlew …` unless mise is activated in the shell; this plan's commands assume it.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-13 | Information Disclosure | Secret staged for commit | high | mitigate | gitleaks `--staged --redact` in the hook (Task 1); the hook is bypassable, so CI scans the full history (plan 01-11) and GitHub push protection is enabled (plan 01-13) |
| T-01-14 | Information Disclosure | Synthetic test token leaking into history | medium | mitigate | Token generated at run time into a scratch file that is deleted; never written into plans, SUMMARY or committed files (Task 1 step 3b-c) |
| T-01-15 | Elevation of Privilege | Hook executes repository code (Gradle, scripts) on commit | low | accept | Only code already in the contributor's own clone runs; the hook is opt-in via `lefthook install` |
| T-01-16 | Information Disclosure | Build Scan publishing build data | medium | mitigate | Scans only with an explicit `--scan`; never in CI; documented in `docs/performance.md` (Task 2) |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; all tools come from `mise.toml` cleared by the legitimacy gate in plan 01-03 |
