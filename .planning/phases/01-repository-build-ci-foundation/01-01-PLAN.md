## Phase Goal

**As a** contributor, **I want to** clone the repository, install pinned tools, and build and check the whole multi-project build with one command, **so that** every commit and pull request is automatically formatted, analysed, licence-checked and governed.

<objective>
Tracer slice of the walking skeleton: a fresh clone builds and tests the sample module end to end through
the `build-logic` conventions, the `:platform` module and the version catalog, with ktfmt + SPDX headers,
strict detekt (`comments` rules), Dokka `failOnWarning`, configuration cache and isolated projects all on,
and TestKit tests that prove the conventions in isolation.

Purpose: every later plan (formatting, governance checks, CI) plugs into this build. Proving the
architecture first (D-02, D-04, D-19) means a dead end costs one commit, not ten.
Output: Gradle wrapper, settings, catalog, three convention plugins, `:platform`, `:tooling:convention-sample`
(D-22), detekt/Spotless config, `functionalTest` suite with a reusable `GradleFixture`.

Phase 1 slice of whole-project requirements: INFRA-09 here covers the catalog, `.java-version` and the
generated daemon-JVM file (the literal check is plan 01-04; container images, `packageManager` and the
Gradle Node plugin belong to Phases 2, 5 and 6). INFRA-10 here covers configuration cache, build cache,
parallel execution, isolated projects, daemon JVM criteria and JVM args (CI caching is plan 01-09,
gradle-profiler is plan 01-05; Testcontainers and buildpack caches are Phases 2 and 6). TEST-13 here
covers Kotlin (detekt); Biome for TypeScript arrives with the frontend in Phase 5.
</objective>
