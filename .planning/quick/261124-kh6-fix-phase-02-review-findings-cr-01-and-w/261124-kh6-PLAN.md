Since the 2026-11-24 amendment of ADR-0015 the merge hook is the single confirmation point for governed work done in an
agent worktree, so every bypass it has is a bypass of AIDEV-08.

Planner decisions (scope author-approved; the choices below are Claude's discretion within it):
- WR-02 is fixed in the lexer (fail closed = ask). Brace expansion that assembles the merge word itself out of pieces
  (`mer{g,}e`, `merg{e..e}`) never mentions a merge and leaves at the early probe, exactly like the parameter-expansion
  case already listed, so it goes to ADR-0015 Residual risks. So does a value of a merge option that splits into several
  words (`git merge -m {x,feat} y`, or an unquoted `$MSG`), because the lexer does not record whether an expansion is
  quoted, and asking for every `-m "$MSG"` would add needless prompts.
- WR-03 is implemented, not only recorded: the hook asks when a command that merges also runs a ref-moving git
  subcommand, regardless of order (fail-closed simplicity; textual order is not reliable because the analysis runs by
  substitution depth). The set excludes subcommands that only add commits on top of HEAD, which keep every merge base.
- WR-04: the edit hook is fixed. The five `Edit(/**/<name>)` ask rules keep prompting inside agent worktrees: they anchor
  at the session root and match any depth, and `checkClaudeAskRules` requires exactly one `Edit(/<entry>)` rule per
  entry. Replacing the `**/` entries with explicit directories would drop coverage of nested configs that these tools
  read from any directory, so the over-asking is recorded as a residual in ADR-0015. ADR-0004 (its line 49 concerns the
  root-anchored `.planning/config.json` rule) and `.claude/CLAUDE.md` (it speaks only of the hooks) stay true and stay
  unchanged.
- Dedupe happens once, when the reason is assembled, with a linear pipeline, so none of the `PROBLEMS+=` sites change.

The executor runs in an agent worktree. `scripts/governance/**` and `scripts/doctor.sh` are governed paths: edit them
with the Edit and Write tools, never with shell writes (`sed -i`, redirects, heredocs). Out of scope: STATE.md (the
orchestrator removes the dedupe todo) and `02-REVIEW-DISPOSITION.md` (the orchestrator records the fixes with the commit
hashes), `.claude/settings.json`, `governance/governed-paths.txt`, any Kotlin or Gradle change.

Purpose: AIDEV-08 (confirmation before governed changes reach the main checkout), AIDEV-07 (doctor and the GSD pin),
UPS-01 and UPS-03 (upstream records are the repository's truthful source on upstream contributions).
Output: hardened hooks with tests, an updated ADR-0015, a validating doctor, and two corrected upstream records.
